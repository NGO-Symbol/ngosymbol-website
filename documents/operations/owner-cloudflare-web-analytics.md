# Cloudflare Web Analytics: токен

Безкоштовна статистика **без кукі**: кількість відвідувань, сторінки, країни, швидкість. Вона працює для всіх відвідувачів
без банера, тому її описано на сторінці конфіденційності (`/privacy`). Сайт `symbol.ngo` працює в режимі «DNS only»
(без проксі Cloudflare), тому автоматичне підключення недоступне: код сайту сам додає скрипт, а вам потрібен лише
**токен**. Час: 10 хвилин. Технічні подробиці: [`analytics.md`](analytics.md).

## Кроки

1. Відкрийте <https://dash.cloudflare.com> і увійдіть в акаунт, де лежить домен `symbol.ngo`.
2. У лівому меню: **Analytics & logs** → **Web analytics** (на старому інтерфейсі просто **Web Analytics**).
3. **Add a site**.
4. У полі **Set up hostname** введіть `symbol.ngo`, виберіть підказку, що з’явилася, → **Done**.
   (Якщо Cloudflare пропонує «автоматичне підключення» чи «Enable»/«Proxied», це не для нас: сайт не проксується. Оберіть ручний варіант.)
5. Натисніть **Manage site**. Побачите фрагмент:

   ```html
   <script defer src="https://static.cloudflareinsights.com/beacon.min.js" data-cf-beacon='{"token": "…"}'></script>
   ```

   Скопіюйте **лише значення токена** (довгий рядок усередині лапок після `"token":`). Сам фрагмент у сторінки **не вставляйте**: код сайту
   робить це сам і лише на справжньому `symbol.ngo`.
6. Передайте токен тому, хто веде сайт: його вписують у `apps/main/app/data/analytics.ts` → `cloudflareToken`.
   Токен не є секретом (він буде видимий у коді сторінки), але не публікуйте його навмисно.
7. Після публікації сайту (merge) дані з’являться в Cloudflare за кілька хвилин: **Web analytics** → ваш сайт.

## Перевірка

- Відкрийте `https://symbol.ngo/` у вікні, де немає блокувальника реклами; у DevTools → Network має бути запит до `static.cloudflareinsights.com/beacon.min.js`.
- У Application → Cookies жодних кукі від скрипта бути не має. (Cloudflare заявляє, що не використовує кукі й localStorage для статистики.)
- На `localhost` і в попередніх копіях запитів бути **не** має: це робить код.

## Майбутній піддомен виставки

Коли виставка переїде на `documentsart.symbol.ngo`, перевірте в Cloudflare, чи її відвідування видно під тим самим сайтом.
Якщо ні, додайте цей хост у **Manage site** (поле hostname можна редагувати). Не перевірено: чи Cloudflare об’єднує піддомени автоматично.

## Що я не міг перевірити

Не відкривав акаунт Cloudflare; точні назви пунктів меню можуть відрізнятися. Документація:
<https://developers.cloudflare.com/web-analytics/get-started/> (для сайтів без проксі: ручний фрагмент, токен у «Manage site»).
Запити скрипта йдуть на `cloudflareinsights.com`.
