# Telegram-бот для сповіщень: створення, chat id, секрети

Монітор сайту (`.github/workflows/uptime.yml`, опис у [`monitoring.md`](monitoring.md)) пише в Telegram, коли сайт перестає
працювати, коли відновлюється, і попереджає про термін сертифіката (менше 14 днів) і домену (менше 30 днів). Йому потрібні
два секрети: `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`. Поки їх немає, монітор працює, але лише друкує повідомлення в журналі запуску. Час: 15 хвилин.

## 1. Створіть бота в BotFather

1. У Telegram знайдіть **@BotFather** (з синьою позначкою) і натисніть **Start**.
2. Надішліть `/newbot`.
3. Назва бота (як побачать люди), наприклад: `Символ: сповіщення`.
4. Ім’я користувача, **має закінчуватися на `bot`**, наприклад `symbol_ngo_alerts_bot`. Якщо зайнято, спробуйте інше.
5. BotFather надішле **токен** виду `123456789:AA…`. Це пароль бота: нікому не надсилайте, не вставляйте в чати, листи, коміти
   чи сторінки сайту. Якщо токен витік: у BotFather `/revoke` → оберіть бота (отримаєте новий; старий перестане працювати) і оновіть секрет.

## 2. Створіть групу й додайте бота

1. Створіть групу в Telegram (наприклад «Символ: сайт») і додайте тих, хто має отримувати сповіщення (Юрій, Петро, ви).
2. Додайте бота в групу: **Add members** → знайдіть його за іменем користувача.
3. Напишіть у групі будь-яке повідомлення (наприклад `привіт`). Бот отримує лише повідомлення, надіслані після додавання.

## 3. Дізнайтеся chat id групи

Варіант A (без сторонніх ботів):

1. Відкрийте в браузері `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, підставивши свій токен замість `<ТОКЕН>` (без кутових дужок). Не діліться цією адресою: у ній токен.
2. Знайдіть у відповіді `"chat":{"id":-100…` або `"chat":{"id":-…`. Число з мінусом і є **chat id групи** (для супергруп починається з `-100`).
3. Порожня відповідь `"result":[]`? Напишіть у групі ще одне повідомлення й оновіть сторінку.

Варіант B: додайте в групу бота на кшталт @getidsbot або @RawDataBot, він покаже id; потім видаліть його з групи. (Сторонній бот бачить повідомлення групи, тому лише тимчасово.)

Примітка: якщо звичайну групу перетворять на супергрупу, її id зміниться, а оновити секрет доведеться заново. Особистий чат: id це додатне число; бот
може писати вам лише після того, як ви натиснули в ньому **Start**.

## 4. Додайте секрети в GitHub

Потрібні права адміністратора репозиторію `NGO-Symbol/ngosymbol-website`.

Веб-інтерфейс: <https://github.com/NGO-Symbol/ngosymbol-website/settings/secrets/actions> → **New repository secret**:

- Name: `TELEGRAM_BOT_TOKEN`, Secret: токен із кроку 1 → **Add secret**.
- Name: `TELEGRAM_CHAT_ID`, Secret: id групи (з мінусом) → **Add secret**.

Або командний рядок (`gh auth login` виконано; значення введіть у запитанні, не в команді):

```bash
gh secret set TELEGRAM_BOT_TOKEN -R NGO-Symbol/ngosymbol-website
gh secret set TELEGRAM_CHAT_ID -R NGO-Symbol/ngosymbol-website
```

Значення секретів після збереження не можна подивитися, лише замінити.

## 5. Перевірте

1. GitHub → **Actions** → **Uptime** → **Run workflow** → поле `mode` = `test` → **Run workflow**.
2. Через хвилину в групі має з’явитися «🧪 Тест монітора symbol.ngo…». Якщо ні, відкрийте запуск: `Telegram send failed: …` покаже причину
   (найчастіше: `chat not found`, тобто неправильний id або бот не доданий, чи `Unauthorized`, тобто неправильний токен).
3. Режим `daily` перевіряє ще й сертифікат і домен.

Файли робочого процесу мають бути в гілці `main`, інакше розклад не запуститься.

## Що я не міг перевірити

Не створював бота й не додавав секретів: це дії власника. Кроки BotFather і `getUpdates` описані за документацією Telegram Bot API
(<https://core.telegram.org/bots#how-do-i-create-a-bot>).
